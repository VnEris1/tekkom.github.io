Membuat data MySQL

1. Membuat Database

  • CREATE DATABASE nama_database;

2. Mengecek database yang dibuat

  • show tables;
  • (Jika belum keluar maka database belum terbentuk.)

3. Membuat table untuk database.

  • create table nama_table(id int AUTO_INCREMENT, nama varchar(10),tanggal_lahir varchar(20));
  • Ini adalah query untuk membuat table.

4. Membuat isi untuk table.

  • insert into nama_table values("nama", "11-11-1999");
  • Ini adalah query untuk menginput data.
  • Untuk huruf harus menggunakan tanda "isi" dan untuk angka tidak perlu menggunakan "".
