Cara Menginstall MySQL

Langkah-langkah Instalasi MySQL

1. Unduh MySQL Installer

  • Buka situs resmi MySQL di https://dev.mysql.com/downloads/installer/ .
  • Pilih MySQL Installer for Windows (biasanya versi Windows (x86, 32-bit, MSI Installer)).
  • Klik Download dan tunggu hingga proses unduhan selesai.

2. Jalankan Installer

  • Setelah file selesai diunduh, klik dua kali file tersebut untuk memulai instalasi.
  • Jika muncul peringatan keamanan, pilih Yes untuk melanjutkan.

3. Pilih Jenis Setup

  • Developer Default — instal semua komponen umum seperti MySQL Server, Workbench, dan konektor.
  • Server Only — hanya menginstal MySQL Server.
  • Custom — memilih komponen secara manual.
  • Disarankan memilih Developer Default, lalu klik Next.

4. Periksa Kebutuhan Sistem (Check Requirements)

  • Installer akan memeriksa apakah semua komponen pendukung sudah tersedia.
  • Jika ada yang belum, klik Execute untuk menginstalnya secara otomatis.

5. Mulai Instalasi

  • Klik Execute untuk memulai proses instalasi MySQL dan tunggu hingga selesai.

6. Konfigurasi MySQL Server

  • Pilih tipe server (biasanya Standalone MySQL Server).
  • Tentukan port (default: 3306).
  • Buat password untuk user root (administrator), lalu klik Next.

7. Mulai Layanan MySQL

  • Pastikan opsi Start MySQL as a Windows Service dicentang.
  • Klik Execute untuk menjalankan server MySQL.

8. Selesai dan Uji MySQL Workbench

  • Setelah instalasi selesai, buka MySQL Workbench.
  • Login menggunakan username root dan password yang sudah dibuat.
  • Jika berhasil masuk, berarti MySQL sudah terpasang dengan benar.
